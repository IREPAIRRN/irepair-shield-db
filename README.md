## What a result means

A match is an **indicator**, not a diagnosis: it says a name, address or file known from published research was
found on the phone, and that a closer forensic look is warranted. **A clean result lowers suspicion; it does not
rule out spyware** — tools of the Pegasus class change their infrastructure, and a list can only know what has
already been published.

## How the app uses it

The app downloads the three files over HTTPS from this repository, then checks each one before using it:

1. the detached Ed25519 signature (`<file>.sig`) must verify against the public key **built into the app**;
2. the content must pass the app's own validation (shape, allowed characters, counts);
3. the version must not be older than the one already installed.

A file that fails any step is ignored and the copy shipped with the app keeps working. Nothing from a phone is
ever sent here: the app only downloads.

## Verify it yourself

```
git clone https://github.com/IREPAIRRN/irepair-shield-db
cd irepair-shield-db
node verify.js
```

`verify.js` has no dependencies (Node 18 or newer). It checks every signature and the SHA-256 values in
`manifest.json`.

Public key (Ed25519, raw 32 bytes, base64 — the same key signs all three files):

```
gUHODJCm2LX6y+BzV5p8wrOwvIxCeX4dcWnmPFmq0jU=
```

The key is also in `public-keys.json`. Because that file sits next to the data, it only protects against damage

never published: it exists only as an encrypted secret of the build pipeline and offline with the maintainer.

## File format

All three files are JSON with `version` (integer, `YYYYMMDD`), `updated` (`YYYY-MM-DD`) and the entries:

- `malware-signatures.json` — `signatures`: `{ "<package>": { "name", "risk", "category" } }`
- `malware-hashes-core.json` — `hashes`: `{ "<sha256>": [name, family, category, severity] }`
- `malware-iocs.json` — `packages`, `processes`, `paths`, `domains`, `emails`: `{ "<value>": [name, category, severity] }`.
  `count` is packages + processes + paths + domains (kept that way so older app versions accept the file);
  `emails` come on top of it.

`manifest.json` lists the version, size and SHA-256 of each file, the totals and the sources.

## Reporting a false positive

If an entry flags a legitimate app or address, write to rimini@i-repair.it with the entry and why it is
wrong. Entries are not accepted from outside; reports are checked and fixed at the source.
