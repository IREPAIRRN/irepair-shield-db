Changes made (ODbL 4.6: the method used to make the alterations)
----------------------------------------------------------------
  Taken from Exodus Privacy, MODIFIED. The file is a SELECTION, not the whole database:

   1. only trackers filed under an ADVERTISING category are considered. Exodus labels these
      "Ads"; "Advertisement" is accepted as well, because the label has changed over time;
   2. a tracker filed as crash reporting is dropped: it is never what this is looking for;
   3. of those, only the ad networks named in the curated list in electron/adwareSdk.js
      (AGGRESSIVE) are kept. That list names advertising networks only, and the NEVER rules
      next to it additionally refuse any name that says analytics or crash reporting, so no
      measurement SDK can get in through it. A network Exodus files under BOTH "Ads" and
      "Analytics" is still an advertising network and is kept — the curated name decides, not
      the extra label. The two networks that are in nearly every free app, Google AdMob and
      Meta / Facebook Audience Network, are deliberately EXCLUDED: their presence says
      nothing about an app;
   4. for each kept tracker, only its code signature (a Java package prefix) and its name are
      kept. Network signatures, descriptions, websites, dates and ids are not redistributed;
   5. prefixes are lower-cased where the package grammar allows, de-duplicated and sorted;
      anything that is not a plain Java package prefix is dropped.

  The exact selection rule is the code in scripts/build-adware-sdk.js and the AGGRESSIVE list
  in electron/adwareSdk.js, both public.
